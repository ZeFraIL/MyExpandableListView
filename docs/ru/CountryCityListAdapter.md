# Описание класса: CountryCityListAdapter

## 1. Общая информация
*   **Имя класса:** `CountryCityListAdapter`
*   **Тип:** Адаптер (наследует `BaseExpandableListAdapter`)
*   **Назначение:** Этот класс работает как «переводчик» или «мост». Список `ExpandableListView` не умеет напрямую показывать данные из `HashMap`. Адаптер берет сырые данные и превращает их в визуальные строки, которые мы видим на экране.
*   **Взаимодействие:** Создается в `MainActivity` и поставляет данные для отображения в списке.

## 2. Переменные (Поля класса)

| Имя | Тип | Назначение | Где используется |
| :--- | :--- | :--- | :--- |
| `context` | `Context` | Нужен для создания визуальных элементов из XML-файлов (инфлейт). | В методах `getGroupView` и `getChildView`. |
| `countries` | `HashMap<String, ArrayList<String>>` | Сами данные: страны и их списки городов. | Почти во всех методах для получения данных. |

## 3. Методы класса

### Имя метода: `getGroupCount`
*   **Тип:** `public`
*   **Возвращает:** `int` (Количество стран).
*   **Что делает:** Сообщает списку, сколько в нем основных групп (стран).

### Имя метода: `getGroupView`
*   **Тип:** `public`
*   **Возвращает:** `View` (Визуальная строка для страны).
*   **Логика:**
    1.  Проверяет, есть ли старая строка для повторного использования.
    2.  Если нет — создает новую из стандартного макета.
    3.  Устанавливает размер шрифта **25dp** и **красный** цвет.
    4.  Пишет название страны.
*   **Когда вызывается:** Когда списку нужно отрисовать название страны.

### Имя метода: `getChildView`
*   **Тип:** `public`
*   **Возвращает:** `View` (Визуальная строка для города).
*   **Логика:** Делает то же самое, что и для страны, но использует шрифт **20dp** и **пурпурный** (Magenta) цвет.
*   **Когда вызывается:** При раскрытии страны, чтобы показать список городов.

## 7. Общая логика
Список `ExpandableListView` постоянно «спрашивает» адаптер: «Сколько у тебя элементов?» и «Как мне нарисовать второй элемент?». Адаптер заглядывает в свои данные и выдает готовый результат.

## 8. Объяснение простыми словами
**Аналогия: Переводчик.**
*   **Данные** — это книга на иностранном языке (код Java).
*   **Пользователь** понимает только картинки (интерфейс).
*   `CountryCityListAdapter` — это **Переводчик**, который читает книгу и пересказывает её так, чтобы пользователю было всё понятно: рисует большие красные заголовки для Глав (стран) и текст поменьше для Абзацев (городов).
