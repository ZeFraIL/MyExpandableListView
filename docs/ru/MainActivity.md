# Описание класса: MainActivity

## 1. Общая информация
*   **Имя класса:** `MainActivity`
*   **Тип:** Activity (Активность/Экран)
*   **Назначение:** Это главный экран приложения. Он выполняет роль «мозга», который координирует данные (списки стран и городов) и визуальный компонент (`ExpandableListView`). Он отвечает за запуск приложения, подготовку информации для показа и реакцию на действия пользователя (клики).
*   **Взаимодействие:** Создает и использует `CountryCityListAdapter` для заполнения списка. Также взаимодействует с системой Android для показа всплывающих сообщений (`Toast`).

## 2. Переменные (Поля класса)

| Имя | Тип | Назначение | Где используется |
| :--- | :--- | :--- | :--- |
| `context` | `Context` | Хранит информацию о среде приложения (контекст). | В сообщениях `Toast` и при создании адаптера. |
| `countryCityMap` | `HashMap<String, ArrayList<String>>` | Словарь, где название страны (Ключ) связано со списком её городов (Значение). | В `initData()`, `initElements()` и при кликах. |
| `countries_list` | `ArrayList<String>` | Простой список имен стран (USA, UK, Poland). | В `initData()` и для определения нажатой страны. |
| `citiesInUSA` | `ArrayList<String>` | Список городов США. | В `initData()`. |
| `citiesInUK` | `ArrayList<String>` | Список городов Великобритании. | В `initData()`. |
| `citiesInPoland` | `ArrayList<String>` | Список городов Польши. | В `initData()`. |
| `elvCountryCity` | `ExpandableListView` | Визуальный элемент списка на экране. | В `initElements()` и для настройки слушателей нажатий. |
| `adapter` | `CountryCityListAdapter` | «Мост», который берет данные из списков и передает их в `ExpandableListView`. | В `initElements()`. |

## 3. Методы класса

### Имя метода: `onCreate`
*   **Тип:** `protected`
*   **Возвращаемое значение:** `void` (ничего)
*   **Параметры:**
    | Имя | Тип | Описание |
    | :--- | :--- | :--- |
    | `savedInstanceState` | `Bundle` | Данные из предыдущей сессии (если приложение было перезапущено). |
*   **Логика:**
    1.  Вызывает стандартный код запуска Android через `super.onCreate`.
    2.  Устанавливает внешний вид через `setContentView`.
    3.  Вызывает `initData()` для подготовки списков.
    4.  Настраивает **слушатель групп**: при нажатии на страну появляется `Toast` с её названием.
    5.  Настраивает **слушатель элементов**: при нажатии на город появляется `Toast` с названием города.
*   **Когда вызывается:** Автоматически системой Android при запуске приложения.

### Имя метода: `initData`
*   **Тип:** `private`
*   **Логика:** Заполняет списки стран и городов вручную и связывает их в `HashMap`. В конце вызывает `initElements()`.
*   **Когда вызывается:** Из `onCreate()`.

### Имя метода: `initElements`
*   **Тип:** `private`
*   **Логика:** Инициализирует переменную `context`, находит список на экране по ID и подключает к нему адаптер с данными.
*   **Когда вызывается:** В конце `initData()`.

## 4. Жизненный цикл
*   **`onCreate()`**: Вызывается при создании экрана. Здесь происходит начальная настройка. Это единственный метод жизненного цикла, явно используемый в этом классе.

## 5. Взаимодействие с интерфейсом (UI)
*   **Элементы:** `ExpandableListView` (раскрывающийся список).
*   **Связь:** Используется `findViewById(R.id.elvCountryCity)` для связи кода с XML-разметкой.
*   **События:** Обработка нажатий на группы (страны) и дочерние элементы (города).

## 7. Общая логика
Класс работает по цепочке: **Запуск -> Заполнение данных -> Поиск UI-элемента -> Подключение адаптера -> Ожидание нажатий**.

## 8. Объяснение простыми словами
**Аналогия: Меню в ресторане.**
*   `MainActivity` — это **Менеджер**.
*   `countries_list` — это список **Категорий** (Закуски, Основное, Десерты).
*   `countryCityMap` — это **Подробное меню**, где записано, какие блюда входят в какую категорию.
*   `ExpandableListView` — это **Папка с меню**, которую держит клиент.
*   `Adapter` — это **Официант**, который берет информацию с кухни (данные) и приносит её на стол клиенту (экран).

Когда клиент (пользователь) нажимает на категорию, Менеджер (Activity) вежливо сообщает ему, что именно было выбрано.
