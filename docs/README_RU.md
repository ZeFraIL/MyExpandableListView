## 🎯 Цель проекта
•	**Какую задачу решает приложение:** Демонстрирует использование компонента `ExpandableListView` для отображения иерархических данных (группы и дочерние элементы).
•	**Почему эта задача важна:** Иерархические списки часто используются в мобильных приложениях для структурирования информации (категории товаров, настройки, списки стран и городов).
•	**Целевая аудитория:** Разработчики, изучающие основы UI-компонентов Android.
________________________________________
## 📌 Требования к приложению
### Функциональные требования
•	Отображение списка стран.
•	Раскрытие списка городов при нажатии на страну.
•	Отображение всплывающих уведомлений (Toast) при клике на группу или элемент.
### Нефункциональные требования
•	**Производительность:** Мгновенная реакция на нажатия.
•	**Удобство использования:** Интуитивно понятный интерфейс стандартного списка.
•	**Надёжность:** Обработка пустых состояний (проверка на null при инициализации).

## 🧠 Общая архитектура
•	**Выбранный подход:**
–	MVC (Model-View-Controller)
•	**Почему выбран именно он:** Для небольшого демонстрационного проекта MVC является самым простым и эффективным способом разделения данных и отображения.
•	**Основные компоненты системы:**
– `MainActivity`: Контроллер и представление.

`[MainActivity]` –> `[CountryCityListAdapter]` –> `[BaseExpandableListAdapter]`

________________________________________
## 🧩 Подробное описание классов
### 📌 Класс: MainActivity
**Роль:** Главный экран приложения.
**Ответственность:** Инициализация данных, настройка `ExpandableListView`, обработка событий нажатия.
**Основные методы:** 
- `onCreate()` — установка layout и запуск инициализации.
- `initData()` — наполнение списков стран и городов.
- `initElements()` — поиск View и установка адаптера.
**Взаимодействие с другими классами:** Создает экземпляр `CountryCityListAdapter` и передает ему данные.

### 📌 Класс: CountryCityListAdapter
**Роль:** Адаптер для `ExpandableListView`.
**Ответственность:** Создание View для групп (стран) и дочерних элементов (городов), управление данными.
**Почему используется:** Наследуется от `BaseExpandableListAdapter` для кастомного отображения элементов.
________________________________________
## 🔄 Диаграмма работы приложения
1. Запуск приложения.
2. `MainActivity` инициализирует `HashMap` с данными.
3. `ExpandableListView` запрашивает данные у адаптера.
4. Пользователь нажимает на страну -> раскрывается список городов.
5. Пользователь нажимает на город -> появляется `Toast` с названием города.

## ⚙️ Работа с потоками
•	**Используются ли:** Все операции выполняются в главном (UI) потоке.
•	**Почему выбран этот способ:** Объем данных мал, задержки отсутствуют.
•	**Как предотвращаются:**
–	зависания (ANR): Данные статичны и подгружаются мгновенно.
–	утечки памяти: Отсутствуют длительные фоновые операции.
